# Contributor map

Maps the git author name on a commit to a GitHub handle and a display name.
`scripts/release_context.py` reads the table below. Add a row when a new author
appears; never guess a handle.

Source column: `noreply` = taken from a `users.noreply.github.com` commit email,
`notes` = used in a published release's PR list, `inferred` = not confirmed, check
before publishing.
